# 🐾 VetCare

Site institucional de uma clínica veterinária, desenvolvido com HTML e CSS puros. O projeto apresenta os serviços da clínica, a equipe de veterinários e os canais de contato e agendamento, com layout responsivo para desktop, tablet e celular.

## 📋 Sobre o projeto

O VetCare foi criado para facilitar o contato entre tutores e a clínica. Pelo site, o visitante pode:

- Conhecer os serviços oferecidos (consulta clínica, exames, cirurgia e vacinação)
- Ver a equipe de veterinários
- Entrar em contato com a clínica
- Solicitar o agendamento de um atendimento

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone git@github.com:prycilla-valente/vetcare.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd vetcare
   ```

3. Abra o `index.html` no navegador, ou use a extensão **Live Server** do VS Code (clique com o botão direito no `index.html` → *Open with Live Server*).

## 📱 Responsividade

O layout se adapta a diferentes tamanhos de tela, com breakpoints em `768px` e `480px`. Em telas pequenas, os cards passam a ocupar uma linha inteira.
